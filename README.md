# Event Management System

A full-featured Event Management web application built with vanilla HTML5, CSS3, and modern JavaScript (ES Modules), powered by `json-server`.

## Features
- **Admin Portal**: Manage events (create, edit, cancel), user management (members, verifiers, admins), view booking reports and revenue metrics.
- **Verifier Portal**: Event check-ins, attendee verification, and real-time status.
- **Member Portal**: Browse events, book tickets, view personal bookings, and manage profile settings.
- **Authentication**: Role-based access control (Admin, Member, Verifier) with password reset flow.

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16+)
- npm

### Installation & Run Locally
1. Clone the repository:
   ```bash
   git clone <YOUR_GITHUB_REPO_URL>
   cd Event-Mangement
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the application:
   ```bash
   npm start
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.
